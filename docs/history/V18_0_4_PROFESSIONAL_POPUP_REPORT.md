# Dokkomplekt Universal 18.0.4 — профессиональные popup-сценарии

## 1. Что было перенесено из донорских проектов

Из Dokkomplekt и diary-filler перенесены не жёсткие медицинские окна, а их сильные поведенческие принципы:

- связанные вопросы объединяются в одно модальное окно;
- ошибочный ответ не закрывает окно;
- подтверждённое специалистом значение выше parser/scanner;
- значение повторно используется во всех документах текущего комплекта;
- связанные даты сначала синхронизируются, но каждую можно изменить отдельно;
- профиль документа определяет специфические вопросы.

Медицинский профиль содержит вопросы для выписки, РВК, ВК/МСЭ, больничного, комиссии, дневников и первичного документа. Эти поля не добавлены в нейтральное ядро.

## 2. Конструктор popup-вопросов

Для каждой пользовательской кнопки документа специалист может создать собственный сценарий вопросов. Поддерживаются:

- короткий и многострочный текст;
- дата;
- число и сумма;
- ИНН, КПП, ОГРН/ОГРНИП, СНИЛС, VIN;
- паспортный реквизит;
- классификатор/МКБ-10;
- список вариантов и Да/Нет;
- обязательность;
- режим `if_missing`, `confirm` или `always`;
- раздел окна, подсказка, значение по умолчанию;
- связь с другим полем.

Сохранённый пользовательский сценарий может убрать необязательные автоматические вопросы. Строго обязательные поля шаблона восстанавливаются fail-closed.

## 3. Интеграция со сканером курсором

Выделенный мышью фрагмент можно:

1. назначить смысловому полю текущего case;
2. одновременно добавить как popup-вопрос активного документа;
3. в шаблоне заменить на `{{field.id}}` или вставить placeholder после выбранного текста.

Исходный DOCX/DOCM не перезаписывается.

## 4. Уникальность каждого комплекта

Загрузка нового текста или DOCX/DOCM заменяет case-specific значения, а не смешивает их с предыдущим человеком, договором или пациентом. Кнопка «Новый комплект» очищает данные вручную. Пользовательские шаблоны, popup-сценарии, настройки печати и библиотека блоков сохраняются.
