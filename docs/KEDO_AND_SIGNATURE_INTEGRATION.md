# КЭДО, PDF/A и электронная подпись

Текущий hand-off пакет — технический контейнер. Dokkomplekt не создаёт юридически значимую подпись и не имитирует КЭП.

Для production-интеграции необходим отдельный адаптер провайдера со следующим контрактом:

1. принять неизменяемый PDF/PDF-A и SHA-256;
2. проверить профиль PDF/A через veraPDF или эквивалентный валидатор;
3. подписать через КриптоПро CSP, Госключ или утверждённого оператора;
4. вернуть detached signature, сертификатную цепочку, timestamp и протокол проверки;
5. сохранить provider transaction id и статус доставки;
6. исключить хранение закрытого ключа внутри Dokkomplekt;
7. поддержать идемпотентный повтор без повторной подписи другого содержимого.

Любой адаптер должен быть опциональным модулем и проходить профильную юридическую и криптографическую проверку организации.
