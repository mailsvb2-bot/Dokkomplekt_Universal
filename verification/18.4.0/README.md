# Отчёты проверки 18.4.0

## ВАЖНО: тулчейн отличается от заявленного в rust-toolchain.toml

Проект требует Rust **1.97.0**. Эти прогоны выполнены на **1.91.1**, потому что
`static.rust-lang.org` недоступен из среды сборки, а в репозитории Ubuntu 24.04
наиболее свежий доступный тулчейн — 1.91.

Компиляция возможна: используемые проектом возможности языка
(`is_none_or` — с 1.82, `is_some_and` и `OnceLock` — с 1.70) в 1.91 присутствуют.
Для прогона в `Cargo.toml` временно понижался `rust-version`; **в поставке
он не изменён и по-прежнему равен 1.97**.

Перед релизом эти проверки обязаны быть повторены на 1.97.

## Отношение к каталогу `verification/` уровнем выше

Отчёты в родительском каталоге относятся к 18.3.2 и после изменений 18.4.0
**устарели**. Они сохранены как история и не описывают текущий код.
