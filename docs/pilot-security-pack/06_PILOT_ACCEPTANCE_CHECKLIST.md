# Чек-лист допуска пилота

- [ ] Подписанный installer и основной EXE проверены Authenticode.
- [ ] Offline-runtime bundle проверен по Ed25519/SHA-256/SBOM.
- [ ] Rust fmt/check/clippy/test/audit и Tauri build зелёные для этого fingerprint.
- [ ] Watcher пережил перезагрузку Windows.
- [ ] Проверены Word, PDF, изображения, OCR и выбранные принтеры.
- [ ] Заполнены модель угроз, роли, сроки хранения и incident response.
- [ ] Все пользовательские шаблоны имеют версии, SHA-256 и владельца.
- [ ] Golden-корпус содержит реальные обезличенные документы организации.
- [ ] Shadow-mode достиг согласованного порога точности.
- [ ] High-risk поля не принимаются без evidence/консенсуса.
- [ ] Автопечать разрешена только для утверждённых низкорисковых сценариев.
- [ ] PDF/A проверяется veraPDF, если это требуется процессом.
- [ ] КЭП выполняется реальным провайдером, а не hand-off слотом.
