# Dokkomplekt Universal 18.0.6 — scanner, watcher and print fixes

## Исправленные подтверждённые дефекты

### Подсказки сканера

- Короткие подписи `от` и `до` больше не ищутся как подстроки. Ранжирование использует Unicode-токены и последовательности целых слов, поэтому `работник` не содержит токен `от`, а `договором` — токен `до`.
- Добавлен локальный контекст вокруг выделения: подпись непосредственно рядом со значением весит сильнее, чем слово в другой части документа.
- `bestScannerSuggestion()` возвращает `null`, если лучший вариант не достиг порога и недостаточно оторвался от второго. UI действительно переходит в режим «Программа не уверена — выберите вариант».
- При равной уверенности используется стабильный порядок реестра полей и факт использования поля в шаблонах, а не алфавит заголовка.
- Ранее обученные специалистом правила участвуют в ранжировании; пользовательское поле может стать первым предложением при повторном появлении знакомой подписи.

### Rust cfg и watcher

- В не-Windows ветках scanner-команд явно потребляются аргументы, используемые только под `#[cfg(target_os = "windows")]`, чтобы Clippy на Linux не создавал `unused_variables`.
- При ошибке чтения или обработки DOCX/DOCM рядом с источником создаётся `ИМЯ — НЕ ПРОЧИТАН.txt` с понятной причиной и инструкцией.
- Пока эта заметка не старше источника, watcher не повторяет обработку каждые несколько секунд. После пересохранения исходника повтор запускается автоматически, а заметка удаляется при успехе.
- Открытый интерфейс получает событие со статусом `error`, поэтому сбой виден не только в техническом логе.

### Печать

- Изменение количества копий и режима автопечати синхронизируется с уже установленным watcher без переустановки фонового режима.
- Перед автопечатью watcher перечитывает актуальную конфигурацию.
- DOC/DOCX/DOCM/RTF на Windows отправляются в Word одним COM-вызовом `PrintOut` с заданным количеством копий. Десять копий больше не означают десять запусков `ShellExecute("print")`.
- PDF сохраняет системный fallback; выбор принтера и дуплекса не объявляется реализованным.

## Регрессионная защита

- 9 тестов ранжирования scanner suggestions, включая реальный русский контекст с `работник`, `договором` и адресом;
- DTO-контракт команды обновления watcher;
- пользовательский сценарий обращения к learned rules;
- 10 Python source-contract tests для token matching, неоднозначности, cfg, видимой ошибки watcher, синхронизации копий и одного Word print job.

## Честное ограничение проверки

В среде подготовки архива отсутствуют `cargo`, `rustc`, `rustfmt` и Clippy, а сеть недоступна. TypeScript, Vitest, frontend build и Python-контур выполнены. Изменённый Rust-код не объявляется скомпилированным; коммерческий release gate остаётся fail-closed до запуска `scripts/prepackage_rust_gate.sh` на Rust 1.85+ и Windows smoke-test Word COM.
