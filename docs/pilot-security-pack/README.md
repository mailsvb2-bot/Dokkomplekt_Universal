# Пилотный пакет безопасности и 152-ФЗ

Этот каталог не является сертификатом соответствия и не заменяет работу специалиста по информационной безопасности. Он превращает абстрактную оговорку «шифрование ≠ 152-ФЗ» в проверяемый план внедрения.

Перед обработкой реальных персональных данных организация должна заполнить и утвердить:

1. `01_DATA_FLOW_REGISTER.md` — где появляются, хранятся и удаляются данные;
2. `02_ROLE_MATRIX.csv` — кто имеет доступ к шаблонам, делам, печати, экспорту и журналу;
3. `03_THREAT_MODEL_WORKSHEET.md` — границы системы, нарушители, угрозы и меры;
4. `04_RETENTION_AND_DELETION.md` — сроки хранения источников, комплектов, логов и резервных копий;
5. `05_INCIDENT_RESPONSE.md` — действия при утечке, потере устройства и ошибочной печати;
6. `06_PILOT_ACCEPTANCE_CHECKLIST.md` — критерии допуска shadow-mode и production-mode.

## Обязательное правило пилота

Сначала используется shadow-mode на обезличенном или законно подготовленном корпусе. Автопечать, автоматическая отправка и модельный zero-touch разрешаются отдельно для каждого документа только после измерения точности и утверждения владельцем процесса.
