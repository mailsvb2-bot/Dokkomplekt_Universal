# Реагирование на инциденты

1. Остановить watcher и автоматическую печать.
2. Зафиксировать время, устройство, пользователя, SHA-256 источника и идентификатор дела без копирования лишних данных.
3. Изолировать устройство или сетевую папку.
4. Сохранить защищённый audit export и журналы ОС/печати.
5. Определить затронутые документы, получателей и резервные копии.
6. Отозвать скомпрометированные ключи/доступы, заменить шаблон или sidecar.
7. Повторно проверить правила обучения и последние zero-touch решения.
8. Выполнить уведомления по утверждённому регламенту организации.
9. Возобновить работу только после контрольного shadow-прогона.
