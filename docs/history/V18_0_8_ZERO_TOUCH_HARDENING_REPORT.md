# Dokkomplekt Universal 18.0.8 — zero-touch hardening report

Дата: 18 июля 2026 года.

## Закрытые дефекты

1. **Устаревший attention-файл.** Risk gate и успешная очистка теперь используют stem источника; при успехе удаляется также legacy-имя, включавшее `.docx`/`.docm`.
2. **Ложные плейсхолдеры.** Угловые кавычки и операторы `<<`/`>>` больше не блокируют документ. Неизвестные поля и ошибки шаблона обрабатываются по структурированным результатам рендера.
3. **Печать Office вне Windows.** DOC/DOCX/DOCM/RTF конвертируются в PDF через LibreOffice в отдельной временной папке, затем PDF одним заданием отправляется в `lp`; временные файлы удаляются и ошибки видимы.
4. **Молчаливые ошибки ФИО.** Двухкомпонентное имя классифицируется по словарю имён и признакам фамилии; окончание фамилии `-ич/-вич` не считается отчеством.
5. **DNS-rebinding обновлений.** Проверенные публичные `SocketAddr` закрепляются в отдельном redirect-free HTTPS-клиенте через `resolve_to_addrs`; manifest и пакет получают собственный безопасный pinned client.

## Регрессионная защита

- Rust unit tests для `<<Ромашка>>`, `a << b`, `Мицкевич Анна` и `Анна Петрова`.
- Python source contracts для канонического attention-name, структурированных renderer errors, PDF-before-CUPS, морфологии и DNS pinning.
- Исторический пустой verification-файл заменён явным уведомлением, что он не является доказательством.

## Граница релиза

Этот релиз исправляет фактические ошибки существующего zero-touch-контура. Он не заявляет завершёнными локальную LLM, профессиональный Print Center, реальный Windows/Word desktop E2E, встроенную поставку OCR/LibreOffice sidecar и универсальные коннекторы к каждой внешней системе.
